## ARITHMETIC OPERATORS

These perform mathematical calculations.

Examples:
+, -, *, /, //, %, **

# COMPARISON OPERATORS

These compare two values and return either True or False.

Examples:
==, !=, >, <, >=, <=

# LOGICAL OPERATORS

These combine or reverse Boolean values.

Examples:
and, or, not

# EXPRESSIONS

An expression is anything Python can evaluate to produce a value.

Examples:
5 + 3
10 > 5
True and False
