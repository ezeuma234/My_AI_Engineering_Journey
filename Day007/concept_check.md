# HOW IS RETURN DIFFERENT FROM PRINT()
return does just spit out whatever you give to it like print does, it is able to perform calculations and return values while print is just a display function
# WHAT IS LOCAL SCOPE
this is a variable that is created and used within a code or function and can only be used within those conditions
# WHAT IS GLOBAL SCOPE
This is a variable that is created outside of a code or function and can be used externally
