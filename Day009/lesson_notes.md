# What is a List?
Definition: A mutable data structure used to store multiple items sequence-by-sequence.Syntax: Items are enclosed in square brackets [] and separated by commas.Flexibility: Can store multiple data types (strings, integers, booleans) simultaneously.
# Indexing
Definition: Finding an item by its specific position number.Rule: Python uses zero-based indexing (counting starts at 0, not 1).
# Negative Indexing
Definition: Finding an item by counting backward from the end of the list.Rule: Starts at -1 for the last item, -2 for the second to last, and so on.
# .append()
Action: Adds a single new item to the very end of the list.Impact: Increases the list length by exactly 1.
# .remove()
Action: Deletes the first occurrence of a specific value.Impact: Will trigger an error if the item does not exist in the list.
# .pop()
Action: Removes and returns an item based on its position number.Rule: If no position is specified inside the brackets, it automatically removes the last item.
# len()
Action: A built-in function that counts the total number of items in the list.
