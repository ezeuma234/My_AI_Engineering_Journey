# WHAT IS A LOOP
a loop is a way to repeat a block of code
# WHY DO WE USE LOOPS
We use loops because it makes our code easy to read and it also takes away the stress of having to rewrite the same block of code so many times
# WHAT IS THE DIFFERENCE BETWEEN A FOR LOOP AND A WHILE LOOP
A  for loop is used when we know the amount of times we want to loop and no conditions need to be met
but a while loop is only used when the necessary number of loops are unknown so conditions are set in order to prevent an infinite loop

# WHAT IS AN INFINITE LOOP, AND HOW CAN IT HAPPEN
An infinite loop is a case where no conditions for looping where set so the loop keeps calling itself infinitely until it eventually crashes
it can happen when no conditions are set for an unknown loop
