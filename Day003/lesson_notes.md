# Day 003 - Lesson Notes

## Core Concepts

- A variable is a name that refers to an object.
- An object is data that exists in memory and has a type and identity.
- `type()` tells me the type/class of an object.
- `id()` tells me the identity of an object.
- `=` is used for assignment.
- `==` compares values for equality.
- `is` checks whether two variables refer to the same object.

## Four Basic Data Types

- `str` - used for text.
- `int` - used for whole numbers.
- `float` - used for decimal numbers.
- `bool` - represents `True` or `False`.

## Key Insight

Two variables can contain equal values without referring to the same object.

Two variables can also refer to the exact same object.
