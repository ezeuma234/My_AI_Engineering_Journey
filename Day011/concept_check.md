1. # What is a tuple?
a tuple is an ordered collection of unique values that cannot be changed, this is because tuples are immutable
2. # What is the main difference between a list and a tuple?
tuples are immutable and ordered while sets are not ordered and can still be changed when necessary or needed
3. # Can you access items in a tuple using indexing?
yes you can access items in a tuple through indexing
4. # What does it mean when we say a tuple is immutable?
this means that once the values are imputed they cannot be change (added or removed)
5. # What is a set?
a collection of unique values,that does not keep duplicates and is mutable
6. # What happens to duplicate values in a set?
they are removed and only one value is retained in the set
7. # What does .add() do to a set?
it adds a new value to a set
8. # What is the difference between .remove() and .pop()?
.remove() removes a specified value from a set. .pop() removes an item, with the exact behavior depending on the data structure.
9. # What does the | operator do when used with sets?
that is used to join 2 already existing sets together and form a brand new joint set,it is also called the union of the set
10. # What does the & operator do when used with sets?
this is called the intersection of a set and it takes only the common values between 2 sets to create another set
