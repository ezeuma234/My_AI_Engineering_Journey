# TUPLES
Definition: Ordered collections used to store multiple items in a single variable.
Syntax: Written with round brackets (item1, item2).
# INDEXING
Position: Items are ordered starting at index 0.
Access: Use square brackets to read items (e.g., my_tuple[0]).
# IMMUTABILITY
Unchangeable: You cannot add, remove, or change items once created.
Safety: Protects data from accidental modifications in your code.
# SETS
Definition: Unordered, unindexed collections of items.Syntax: Written with curly brackets {item1, item2}.
# DUPLICATES
Unique Only: Sets cannot contain duplicate items.Auto-Filter: Any duplicates you try to add are automatically ignored.
# .add()
Insert: Adds a single new item to a set.Syntax: my_set.add("new_item").
# .remove()
Delete: Removes a specific item from a set.
Error: Crashes with a KeyError if the item does not exist.
# UNION |
Combine: Joins two sets together.
Result: Returns a new set containing all unique items from both sets.
# INTERSECTION &
Overlap: Compares two sets.
Result: Returns a new set containing only the items found in both sets.
